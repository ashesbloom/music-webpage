# ACRUX 1.0: your music, on a record that spins

**ACRUX is a music player built around a vinyl record.** The record is the player: it spins up and slows down with the
music, and you can grab it to scratch or seek. Play your own songs, a Google Drive folder, and free music from around
the web, all in one library that stays on your computer.

- 💿 **The record is the player.** It has a tonearm and strobe dots, and it takes its colour from each album cover.
- 🗂️ **All your music in one place.** Add songs from this computer, a Google Drive link, or free music online
  (Jamendo, Audius, the Internet Archive, YouTube).
- 🔒 **Yours alone.** There's no account and no tracking. Your library and listening history never leave your computer.

## Install

### 🍎 Mac with Homebrew (easiest)

```sh
brew install --cask ashesbloom/tap/acrux
```

That's it. ACRUX opens straight away, with no security prompts. `brew upgrade` keeps it up to date, alongside the
updates ACRUX installs itself.

### 🍎 Mac with the .dmg

1. Open the `.dmg` and drag **ACRUX** to **Applications**.
2. ACRUX isn't notarized by Apple yet, so the first time you open it, macOS says *"ACRUX" Not Opened*. Press **Done**,
   not Move to Bin.
3. Open **System Settings → Privacy & Security**, scroll down and press **Open Anyway**. You only do this once.

Or, instead of steps 2 and 3, run this once in Terminal:

```sh
xattr -cr "/Applications/ACRUX.app" && codesign --force --deep --sign - "/Applications/ACRUX.app"
```

### 🪟 Windows

Run the installer. It installs just for you, so it doesn't ask for admin rights. ACRUX isn't signed yet, so
SmartScreen may say *Windows protected your PC*. Press **More info**, then **Run anyway**.

### 🐧 Linux

- **.deb:** `sudo apt install ./ACRUX-1.0.0-linux-amd64.deb`. ACRUX then appears in your apps.
- **AppImage:** `chmod +x ACRUX-1.0.0-linux-x86_64.AppImage`, then run it. It needs FUSE 2: on Ubuntu 24.04, install it
  with `sudo apt install libfuse2t64`.

### First launch

ACRUX starts with no music. **Set up ACRUX** walks you through adding your music (this computer, Google Drive, online)
and the free keys that Drive, Jamendo and YouTube need, and it checks each one. It ends with a QR code that brings
ACRUX to your phone. After that, a short tour shows how the record works.

## Keyboard shortcuts

| | |
|---|---|
| <kbd>Space</kbd> or <kbd>K</kbd> | Play / pause |
| <kbd>Shift</kbd> <kbd>N</kbd> · <kbd>Shift</kbd> <kbd>P</kbd> | Next · previous song |
| <kbd>←</kbd> <kbd>→</kbd> · <kbd>J</kbd> <kbd>L</kbd> | Back / ahead 5 s · 10 s |
| <kbd>0</kbd>–<kbd>9</kbd> | Jump to 0–90% of the song |
| <kbd>Shift</kbd> <kbd>↑</kbd> <kbd>↓</kbd> · <kbd>M</kbd> | Volume · mute |
| <kbd>S</kbd> · <kbd>R</kbd> · <kbd>F</kbd> · <kbd>Q</kbd> | Shuffle · repeat · ♥ · queue |
| <kbd>/</kbd> · <kbd>?</kbd> | Search · all shortcuts |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>,</kbd> | Settings |

The single-key shortcuts can be turned off in Settings. Media keys always work.

## Updates install themselves

From now on, ACRUX checks for updates when it starts and every few hours. It downloads a new version in the background,
puts a dot on **Settings**, and installs it when you press **Restart now**. If a new version ever fails to start, ACRUX
goes back to the one that worked. You can turn off automatic downloads in **Settings → Updates**.

## Check your download

Each file's SHA-256 is in [`SHA256SUMS.txt`](https://github.com/ashesbloom/music-webpage/releases/download/v1.0.0/SHA256SUMS.txt).
GitHub also records that every file was built from this repository by its release workflow. To check one with the
[GitHub CLI](https://cli.github.com):

```sh
gh attestation verify ACRUX-1.0.0-mac.dmg -R ashesbloom/music-webpage
```

## Good to know

- **Your data** is in `~/Library/Application Support/ACRUX` (Mac), `%APPDATA%\ACRUX` (Windows) or `~/.config/ACRUX`
  (Linux). `server.log` next to it says what went wrong, if something does. More in the
  [privacy policy](https://ashesbloom.github.io/music-webpage/privacy.html).
- **Unsigned for now.** ACRUX isn't signed by Apple or Microsoft yet, which is why the first launch asks whether you
  trust it. Homebrew handles this for you on a Mac.
- **Linux is new.** Please [open an issue](https://github.com/ashesbloom/music-webpage/issues) if something's off.
- **Collaborators.** The first time you invite people, your firewall asks to let ACRUX use the network. Allow it so
  people on your Wi-Fi can join.
